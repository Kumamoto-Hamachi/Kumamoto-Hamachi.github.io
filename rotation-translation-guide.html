Foundation / extrinsic parameters

回転行列と並進ベクトル

カメラ幾何で頻出する R と t は、難しい記号に見えても、役割は「向きを変える」と「位置をずらす」の二つだけです。このページでは、まず 2D の矢印を動かして仕組みをつかみ、最後に 3D のカメラ座標変換へつなげます。行列を初めて見る人でも、足し算と掛け算を順番に追えば読める構成です。

GOAL 1ベクトルを「向きと長さを持つ数の組」として読める
GOAL 2回転 R と並進 t を、具体的な数で手計算できる
GOAL 3カメラの式 Pc = RPw + t の意味を説明できる
01 / Vector

ベクトルは「数をひとまとめにした矢印」

位置を表すには、横方向だけでなく縦方向の数も必要です。点 P が「右へ 2、上へ 1」の場所にあるなら、位置を P = (2, 1) と書けます。このように複数の数を順番にまとめたものがベクトルです。図では、原点から点 P へ伸びる矢印として描けます。

Position vector

点の住所として読む

(2, 1) は「原点から右へ 2、上へ 1」。成分の順番には意味があり、通常は (x, y)、3D なら (x, y, z) と並べます。

Displacement vector

移動量として読む

(3, −2) は「今いる場所から右へ 3、下へ 2」。同じ数の組でも、文脈によって位置にも移動にもなります。

P=21← 横に (2, 1) と書いても、縦に並べても同じ二つの成分
02 / Translation

並進ベクトル t は、全員に同じ移動を足す

並進（translation）は、回したり伸ばしたりせず、同じ向きに同じ距離だけ平行移動する操作です。点 P に移動量 t を成分ごとに足せば、新しい点 P′ が得られます。

FIG. 1並進はベクトルの足し算スライダーを動かせます
component-wise calculation
P′=P+t

x どうし、y どうしを足します。斜めの矢印を直接計算する必要はありません。

並進では、点どうしの形や距離は変わりません。 図形のすべての頂点に同じ t を足すと、図形全体がそのまま滑ります。原点だけは (0, 0) + t = t へ移るため、t は「移動後の原点の住所」としても読めます。

03 / Rotation matrix

回転行列 R は、長さを保ったまま向きを変える

回転行列（rotation matrix）は、ベクトルに掛けると向きだけを変える数の表です。2D で原点を中心に反時計回りへ θ 回す行列は、下の 2×2 です。cos θ と sin θ は、回した後の横成分と縦成分を分けるための数だと思えば十分です。

R(θ)=cos θ−sin θsin θcos θ,P′=R(θ)P
FIG. 2点 P = (2, 1) を原点のまわりに回す長さは常に √5
row by column

1 行目で、新しい x を作る

x′ = cos θ × x − sin θ × y。行列の 1 行目と、ベクトルの上から下をペアで掛けて足します。

2 行目で、新しい y を作る

y′ = sin θ × x + cos θ × y。同じ元の x, y を、今度は 2 行目と掛けます。

90° の具体例

cos 90° = 0、sin 90° = 1 なので、(2, 1) は (0×2 − 1×1, 1×2 + 0×1) = (−1, 2) になります。

R の 1 列目 = (cos θ, sin θ)

元の x 軸の単位ベクトル (1, 0) が、回転後にどちらを向くかを表します。

R の 2 列目 = (−sin θ, cos θ)

元の y 軸の単位ベクトル (0, 1) が、回転後にどちらを向くかを表します。行列の列は「回した後の軸」です。

回転行列の逆は、角度を反対にした回転です。 R(θ)−1 = R(−θ)。回転行列では、行と列を入れ替えた転置 RT も同じものになるため、R−1 = RT と書けます。

04 / Composition

回してから、ずらす：P′ = RP + t

R と t を一緒に使うと、「向きを変えた後で、別の位置へ運ぶ」操作になります。計算順序は式のとおりで、先に RP を計算し、その結果に t を足します。行列とベクトルの掛け算を先にするのは、通常の掛け算を足し算より先にするのと同じです。

元の点 P(2, 1)
→ R →
回転した点 RP90° なら (−1, 2)
→ + t →
結果 RP + tt = (3, −2) なら (2, 0)
P′=0−11021+3−2=−12+3−2=20

順番を変えると、一般には別の答えです。 R(P + t) は、点だけでなく移動量 t まで回します。RP + t は、回転した後に世界の軸に沿って t だけ動かします。カメラの外部パラメータは RP + t の形です。

05 / Camera coordinates

カメラでは「点を動かす」のではなく、住所を書き換える

ここが最も大切な切り替えです。カメラの式では、現実の点を動かしているわけではありません。同じ点 P を、世界に固定したものさしで測った住所 Pw から、カメラを原点とするものさしで測った住所 Pc へ書き換えています。

点を動かす見方（active）座標系を書き換える見方（passive）
現実の点別の場所へ動く同じ場所に留まる
ものさし固定されたまま世界のものさしからカメラのものさしへ交換
カメラ幾何理解の練習に便利外部パラメータ R, t が行うこと
Pc=RPw+t=R(Pw − C)

C は「世界座標で見たカメラの位置」です。まず Pw − C で、カメラを原点にした相対位置を作ります。次に R を掛けて、世界の軸向きからカメラの軸向きへ成分を読み替えます。二つの式を比べると、t = −RC だと分かります。

FIG. 3世界座標からカメラ座標へ上から見た X–Z 平面
world → camera

t はカメラ位置 C そのものではありません。 t は「世界座標の原点をカメラ座標で表した住所」です。カメラ位置が欲しいときは、式を逆に解いて C = −RTt とします。

初期値では C = (2, 1)、カメラは世界の +X 方向を向き、Pw = (5, 3) です。結果 Pc = (−2, 3) は「点はカメラの左 2 m、前 3 m」という意味になります。

06 / From 2D to 3D

3D でも仕組みは同じ。成分が一つ増えるだけ

3D では P が (X, Y, Z) の 3 成分、t も (tx, ty, tz) の 3 成分になり、R は 3×3 になります。行列の各行とベクトルの 3 成分を掛けて足す規則は、2D とまったく同じです。

XcYcZc= r11r12r13r21r22r23r31r32r33 XwYwZw+txtytz

R の 1 行目は Xc、2 行目は Yc、3 行目は Zc を作ります。OpenCV のカメラ座標は Xc が右、Yc が下、Zc が前です。特に Zc は、ピンホール投影で使う「カメラから見た奥行き」になります。

Extrinsic matrix

R と t を横に並べる

[R | t]=r11r12r13txr21r22r23tyr31r32r33tz

これが 3×4 の外部パラメータ行列です。Pw の末尾に 1 を足した (X, Y, Z, 1) を掛けると、最後の列 t も同じ掛け算にまとめられます。

OpenCV solvePnP

rvec と tvec

solvePnP は R を 9 個の数ではなく、回転軸と角度をまとめた 3 成分の rvec で返します。cv2.Rodrigues(rvec) で 3×3 の R に変換できます。tvec はこのページの t です。

07 / Checkpoint

三問で理解を確認する

答えを考えてから、各カードを開いてください。

Q1. t = (−2, 3) はどう動く？

すべての点を左へ 2、上へ 3 動かします。P = (4, 1) なら P + t = (2, 4) です。

Q2. 90°回転で (1, 0) は？

反時計回りなら (0, 1) です。R の 1 列目を見るだけでも答えられます。

Q3. t はカメラ位置？

違います。t は世界原点のカメラ座標です。世界座標でのカメラ位置は C = −RTt です。
